# eVoteStruct

![Status](https://img.shields.io/badge/status-research%20simulation-blue)
![Language](https://img.shields.io/badge/C++-hierarchical%20model-00599C)
![Affiliation](https://img.shields.io/badge/ISI%20Kolkata-research-navy)

A research based project developed under ISI Kolkata. It explores and simulates secure digital voting for Indian student institutions through literature review, data analysis, and a hierarchical C++ model with institutional verification and two factor authentication.

## At a glance

- Institutional verification before a ballot is accepted
- Two factor authentication in the model path
- Written for a student institution, not a national election
- Author: Parth Pariwandh, Jadavpur University
